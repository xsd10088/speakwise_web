2. 当前产品定位
SpeakWise 是面向中文用户的英语口语练习网页，核心学习闭环是：

选择英语难度。
选择日常使用场景。
阅读并听取目标句和情景对话。
使用浏览器麦克风录音。
将录音转写，并根据目标句显示跟读评分。
点击句子中的单词查看音标/释义、朗读并收藏到生词本。
查看当天对话轮数、发声次数、AI 评分和平均准确率。
进入 AI 口语对话，用文字或录音回答 AI。

当前品牌和页面标题：SpeakWise — 英语口语练习。页面为中文界面，英语内容作为学习材料展示。

4. 主要交互模块
4.1 目标句卡片
用户可以：

查看当前课目标句。
点击 播放示范 播放英语句子。
在 正常 / 较慢 之间切换朗读速度。
点击句子中的单词，打开单词详情并进行收藏或朗读。

浏览器使用 speechSynthesis 和 SpeechSynthesisUtterance 播放英语，不依赖页面内置音频文件。句子朗读语言设置为 en-US。

4.2 情景对话跟读
每一轮对话包含：

角色名，例如 Alex、Mia。
角色类型：练习句或对话伙伴。
英文句子。
语音按钮：使用浏览器语音合成朗读。
翻译按钮：显示/隐藏中文翻译。
录音按钮：针对当前句子录音并进入 AI 跟读评分。

线上构建产物中的组件定位显示，这部分主要在 client/src/pages/Home.tsx 中组装，句子交互主要使用 client/src/components/InteractiveSentence.tsx，逐句录音评分使用 client/src/components/InlineRecorder.tsx。

4.3 浏览器录音
主要组件定位：client/src/components/Recorder.tsx。

已确认的录音流程：

点击开始录音。
调用 navigator.mediaDevices.getUserMedia 获取麦克风权限。
优先探测浏览器支持的 MIME 类型，包括 audio/webm、audio/mp4、audio/ogg;codecs=opus 等。
使用 MediaRecorder 分片采集音频，约每 250ms 触发一次数据收集。
停止录音后合并为 Blob，并生成本地播放 URL。
进入转写处理状态。
显示识别文本、录音时长和错误状态；支持失败后重新识别或重新录音。
录音权限错误、浏览器不支持、无声音等情况均有中文提示。

录音约束：

页面必须使用 HTTPS 才能稳定获得麦克风权限。
真实用户浏览器需要授权麦克风。
当前页面会显示“未连接外部音频库”，说明音频录制使用浏览器能力，音频库并非页面常驻资源。

4.4 转写和评分
构建产物中可确认的接口调用：

前端使用 tRPC 客户端。
API 基础路径包含 /api/trpc。
录音转写调用：voice.transcribe.useMutation()。
认证/会话请求头会尝试读取 sessionStorage 中的 manus-cookie，随后向 tRPC 请求发送 Bearer 信息。

逐句评分卡显示以下字段：

总分 overallScore，以 /100 展示。
发音 pronunciationScore。
流利度字段。
准确度 accuracyScore。
真实录音识别结果 transcript。
录音匹配率 transcriptAccuracy。
词错率 wordErrorRate。
AI 总结 summary。
问题指出 issues。
改进建议 suggestions。

需要注意：公开构建产物能确认转写 mutation 和评分结果的数据结构，但未能确认后端评分 procedure 的完整名称、模型供应商、鉴权配置、音频上传实现和费用策略；这些必须在本地源码和服务端配置中进一步核验。

4.5 AI 口语对话
页面包含独立的 AI 口语对话模块：

AI 教练先发送英文问题。
用户可以输入文字后发送。
输入中文时，界面会先生成英文表达建议。
用户也可以通过下方录音组件回答。
AI 回复文字出现时，同时尝试播放语音。
当前场景支持重读/重新开始。
AI 对话录音完成后会显示“录音已保存并已转写”等状态。

线上页面所展示的首条 AI 内容为：Hi, I'm Alex. Nice to meet you.。

4.6 生词本
主要逻辑定位：client/src/components/InteractiveSentence.tsx。

确认行为：

句子按单词拆分，每个词可点击。
点击后显示词形、音标、中文释义。
支持点击扬声器朗读单词。
支持加入/移出生词本。
生词本条目会保存原始例句和保存时间。
顶部导航和侧栏同步显示单词数量。
支持从生词本中逐词朗读和删除。

本地存储 key：

speakwise-vocab-notebook：生词本 JSON 数组。

内置词典覆盖一批常用词，并带有词形还原/简单变形处理；未命中的词会生成保守的占位音标和释义，后续建议核查是否需要接入正式词典服务。

4.7 今日统计和进度
页面右侧当前显示：

对话轮数。
发声次数。

平均准确率。

5. 技术架构判断
5.1 前端
React。
TypeScript 源码，构建产物保留 .tsx 文件 data-loc。
单页应用，入口包含 client/src/main.tsx。
页面主要入口：client/src/pages/Home.tsx。
404 页面：client/src/pages/NotFound.tsx。
使用 React hooks 管理页面状态、录音状态、播放状态和弹层状态。
UI 组件中存在通用 Button、Card、Tooltip、Sonner 等封装。
CSS 构建产物约 171 KB，包含大量页面模块和响应式样式。

5.2 数据和网络
tRPC 客户端连接 /api/trpc。
使用查询/Mutation 风格的客户端数据访问，构建产物中可见 TanStack Query 相关实现。
页面课程和对话内容主要是前端内置常量/对象，不像是从课程数据库动态加载。
生词本和今日统计主要保存在浏览器 localStorage。
主题上下文存在 client/src/contexts/ThemeContext.tsx，当前默认界面为浅色。

5.3 视觉和响应式
已确认的字体：

DM Sans：正文/界面。
Space Grotesk：标题或品牌强调。
另有 Georgia/系统字体回退。

已发现响应式断点包括：480px、620px、720px、780px、820px、1080px，以及 Tailwind 风格的 rem 断点。

页面视觉特点：

白色/米白背景。
蓝色作为主要操作和进度色。
卡片式布局，桌面端左侧主内容 + 右侧统计栏。
大号课程标题和浅蓝目标句卡片。
录音波形、状态 chip、评分环形图等学习反馈视觉。
页面包含无障碍属性，如 role="tab"、aria-label、aria-live、键盘关闭评分卡等。

6. 目前最重要的开发边界
本地数据不是云端进度：换浏览器、清理缓存或换设备后，生词本和今日统计可能丢失。
录音依赖浏览器权限与兼容性：需要分别测试 Chrome、Edge、Safari、移动端浏览器和拒绝权限场景。
AI 转写/评分依赖 /api/trpc 服务：需要核实开发环境是否有相同服务、环境变量和鉴权方式。
课程内容可能由大对象集中维护：新增课程、编辑角色对话和翻译时，可能需要修改 Home.tsx 或同级数据模块。
听力训练虽然有页面入口：线上首页可见导航，但本次未深入操作该模块；需要拿到源码后确认是否为完整独立功能、是否共享课程数据。
线上构建与本地源码可能有版本差异：不能直接覆盖本地文件，也不应把线上压缩 JS 当作可维护源码。
未发现公开的 package.json：服务器对非静态文件路径返回 SPA fallback，因此依赖和脚本命令必须从本地项目核对。
